# مكتب وليد مجدي — كتالوج جملة

موقع عربي RTL ثابت، مناسب للنشر على GitHub Pages. يعرض صور المنتجات ويتيح البحث والتصفية وتجهيز طلب متعدد الأصناف وإرساله برسالة جاهزة إلى واتساب.

## تشغيل محلي
افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا بسيطًا من مجلد المشروع:

```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (يجب أن يكون `index.html` في الجذر).
2. من المستودع افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
4. انتظر انتهاء النشر وافتح رابط GitHub Pages الذي يظهر في صفحة الإعدادات.

## بيانات المكتب
- الاسم: مكتب وليد مجدي
- الهاتف/واتساب: `+201126387853`
- الأسعار: لا توجد أسعار ثابتة على الموقع؛ يتم الاتفاق حسب الكمية من خلال واتساب.

## تعديل المنتجات
- بيانات المنتجات وأسماؤها وتصنيفاتها في `products.js`.
- الصور في مجلد `assets/`.
- التصميم في `style.css`، والسلوك والتصفية وسلة الطلب في `app.js`.
- الأسماء الحالية «منتج رقم 001» وما بعدها أسماء مؤقتة حسب ترقيم الصور. يُفضّل استبدالها بأسماء فعلية قبل الإعلان عن الموقع.

## ملاحظات مهمة قبل الإطلاق
- تمت إضافة 107 صورة من الأرشيف المقدم وتحويلها إلى WebP لتقليل حجم الموقع.
- الصور الأصلية لا تثبت السعر أو المخزون أو العمر المناسب؛ لذلك لم تتم إضافة أسعار أو وعود توافر أو شهادات جودة.
- يجب مراجعة أسماء المنتجات وتصنيفاتها والكميات المتاحة يدويًا. أضف عنوان المكتب ومناطق التوصيل وسياسة الاستبدال فقط بعد تأكيدها من صاحب النشاط.
- الموقع لا يجمع بيانات دفع ولا ينفّذ دفعًا إلكترونيًا؛ الطلب يُرسل يدويًا إلى واتساب للمراجعة والاتفاق.
